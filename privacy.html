Privacy policy

Trading Project Backup · Updated October 10, 2026

This personal configuration uses restic and rclone on its owner's computer to back up files to the owner's Google Drive. It is not offered to other users.

Data and access

Google authorization permits the configuration to create, list, read, update and delete files it creates in Drive through the drive.file permission. This access supports uploading encrypted backups, checking their integrity, and restoring them. Backup deletion occurs only when separately requested by the owner.

Restic encrypts backup contents and original file metadata locally before upload. Google Drive receives the encrypted repository objects and can observe storage metadata, including object sizes, upload times and access activity. The restic encryption password is not sent to Google.

Storage and sharing

Google authorization credentials are stored locally for the owner's backup connection. They are not published on this website. Backup data remains in the owner's Drive and is not sold, used for advertising, used to train AI models, or intentionally shared with other users by this configuration.

Data obtained through Google APIs is used only for this personal backup and recovery purpose, in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Backups remain until the owner explicitly deletes them. The owner can revoke this application's access through Google Account settings; revoking access does not itself delete existing backups. The owner controls deletion through their Drive account or an explicitly authorized backup maintenance operation.

This website

These static information pages contain no sign-in form, advertising, analytics scripts or backup contents. The website hosting provider may process normal web request information under its own privacy policy. Questions about this personal configuration can be directed to the support address shown on its Google consent screen.
