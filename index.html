Trading Project Backup

A private, personal backup configuration using restic and rclone to store encrypted backups in its owner's Google Drive.

Restic encrypts backup contents locally before rclone transfers them to Google Drive. The owner can later retrieve and verify those backups to recover files.

The Google authorization requests access to files created by this application, using the drive.file permission. It does not request access to all existing Drive files.

This configuration is for its owner's use only. It is not a public backup service and does not offer sign-up or accept other users' data.
